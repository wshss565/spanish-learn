## 4. 本轮最重要的新发现（结构性缺陷，历轮 22 次均未发现）

**B2 词库对该类词只保留了「缺重音拼错」的形式，正确拼写形态在 B2 内根本不存在。**

直接探针（`_acc23.txt` 自检段）实测：

| 词 | 正确形（带重音）在 B2？ | 正确形所在等级 | 缺重音形在 B2？ |
|---|---|---|---|
| `música` | **否** | a1 | 是（`musica`） |
| `día` | **否** | a1 | 否（B2 内 `dia` 也不存在） |
| `adiós` | **否** | a1 | 否 |
| `policía` | **否** | a1 | 是（`policia`） |
| `teléfono` | **否** | a1 | 是（`telefono`） |
| `médico` | **否** | a1 | 是（`medico`） |
| `país` | **否** | a1 | 是（`pais`） |
| `niño` | **否** | a1 | 是（`nino`） |
| `cámara` | **否** | a1 | 是（`camara`） |

**它对决策的三个直接影响**：

1. **这批词在定义上就无法补「正确」例句** —— 例句必须原样包含目标词，写出来必然教错拼写
   （如 `Policia trabaja aquí.`）。所以它们**不属于「还没补到的词」，而属于删除/修正 pass 的对象**。
   这是对停止条件的一条**新理由**，比历轮「找不到 150 条干净词」更根本。
2. **删除 pass 是安全的、不会丢词汇** —— 正确拼写已在 A1/A2/B1/C1/C2 被收录并（多数）已配例句，
   删掉 B2 的错拼版只是去重，站内不会因此少教一个词。
3. 若产品上希望 **B2 自己**保留正确拼写，则该动作是**改拼写（数据编辑）而非删除** —— 需另行授权，
   本轮未做（任务明令禁止改已有词条）。
