## 三、本轮新取证（三项，均历轮未做）

### 3.1 错释义的「归属」：错误是单侧的，全在 `zh`，不在 `exZh`

第 85 轮只证明「`zh` 与 `exZh` 零共同汉字」，未区分**哪一侧错**。本轮对候选池 1,240 条做 `exZh` 侧机械体检：

| 信号 | 命中 |
|---|---|
| 空串 / C1 控制区 / mojibake / 无汉字 / 含未翻译拉丁串 | **0** |
| 过短（≤3 汉字） | 2（`desorden→很乱。`、`cerradura→锁坏了。`，均为例句本身短句，**非缺陷**） |

⇒ **`exZh` 侧机械缺陷 = 0**。结合第 84 轮「例句不含原词 = 0 条」，可判定：
**错误集中在 `zh` 单侧，例句与例句译文两个字段是干净的。**

这条有直接工程含义：**P1 修复只需改 `zh` 一个字段，不必触碰 `ex` / `exZh`**，
也就不会牵动已经通过校验的 4,361 条例句。

### 3.3 错法归类：主要根因是「跨语言义项错配」，不是单一 UI 词典污染

18 条 W 桶的错法分布：

| 错法 | 占比 | 实例 |
|---|---|---|
| **取了另一词的义项（跨语言/同源义项错配）** | **61.1%（11/18）** | `canciller→校长`（英语 chancellor 的大学义）、`apertura→孔径`（aperture 光学义）、`anular→环面`（形容词 annular 义，词条却是动词 anular=cancelar）、`costas→费用`（costs vs coasts）、`carpa→鯉`（carp vs tent）、`conjunto→合办预算`、`votación→参与率`、`selección→选中范围`、`fibras→小鱼` |
| 技术/软件术语污染 | 27.8%（5/18） | `gotas→颜色异或的胶块`、`diálogo→列表框`、`ratito→比例` |
| 音译 | 5.6%（1/18） | `palomas→帕洛马斯` |
| mojibake | 5.6%（1/18） | `gravedad→ç°åº¦` |

补充机械核验：用 32 个「软件/工程词典」标志词扫线上 4,361 条 `zh`，**仅命中 7 条（0.2%）**
（`孔径 aperture`、`异或 gotas`、`线程 hilos`、`列表框 diálogo`、`环面 anular`、`端口 babor`、`索引 buscador`）。

⇒ **修正第 86 轮的单因推断**：`empate→手 ：`、`descartar→已显示` 属真实存在的污染通道，
